# Датасет прицепов (свежий парс)

Полностью самостоятельный набор данных. **Не связан** ни с одним другим проектом.
Источник: центр-прицепов.рф/alltrailers — распарсены все карточки товаров.

## Что внутри

| Файл / папка | Что это |
|---|---|
| `index.html` | **Готовый сайт-каталог.** Открой в браузере — фильтры, карточки, галерея. Самодостаточный (данные встроены, фото из `media/`). |
| `catalog.json` | **Главный файл данных.** Все товары, структурировано, с локальными путями к фото (поле `media`). |
| `catalog_raw.json` | То же, но фото — исходными ссылками на CDN (без локальных путей). |
| `media/<id>/01.jpg …` | Все скачанные фото каждого товара (по папке на товар). |
| `product_list.json` | Плоский список всех карточек (name, price, link) — вход для парсера. |
| `scrape.py` | Скрипт сбора данных со страниц (заново пересобрать всё). |
| `download_media.py` | Скрипт скачивания всех фото в файлы. |

## Схема одной карточки (`catalog.json`)

```json
{
  "id": "763623409152",                 // id товара (уникальный)
  "name": "Прицеп «КОМПАКТ» МЗСА 817700",
  "brand": "МЗСА",
  "price": 42336,                        // текущая цена, ₽ (число)
  "old": null,                           // старая/зачёркнутая цена или null
  "sku": "",
  "url": "https://…/tproduct/763623409152-…",  // ссылка на оригинал
  "imgs": ["https://static.tildacdn.com/…jpg", …],   // все фото — ссылки CDN
  "media": ["media/763623409152/01.jpg", …],          // все фото — локальные файлы
  "descr": "Полный текст описания из блока «Подробнее»…",
  "specs": ["Грузоподъёмность, кг: 616", "Полная масса, кг: 750", …],  // плоско
  "characteristics": [                    // то же, структурировано
    {"title": "Грузоподъёмность, кг", "value": "616"},
    {"title": "Полная масса, кг", "value": "750"}
  ]
}
```

## Как использовать под новый каталог

- Читаешь `catalog.json`, рендеришь карточки из полей выше.
- Фото берёшь из `media` (лежат локально) — галерея = весь массив.
- Фильтры удобно строить по `brand`, `price`, `characteristics`.

## Пересобрать заново

```bash
python3 scrape.py           # data → catalog_raw.json
python3 download_media.py    # фото → media/, пути → catalog.json
```
